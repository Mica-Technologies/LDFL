# Advancements

LDFL adds a **Frontline Heroes** tab to the advancements screen (++l++), with a small tree that
walks you through the roles.

| Advancement | Type | How to get it |
| --- | --- | --- |
| **Frontline Heroes** | Root | Pick up any hero's signature item |
| **Hold the Line** | Task | Pick up a **Tank's** signature item: Bulwark Shield, Bulwark Maul or Cragfist |
| **Pressure Point** | Task | Pick up a **Damage** hero's signature item: Bolt Driver, Tinker's Wrench or Longshot Rifle |
| **Keep Them Standing** | Task | Pick up a **Support's** signature item: Solace Staff or Tuning Rod |
| **Patched Up** | Task (after Keep Them Standing) | Get a **Mending Station** |
| **Full Roster** | Challenge | Collect a signature item from **every** hero: one for Bulwark, Monolith, Forgewright, Kestrel, Solace and Chime |

The advancements check your inventory, so crafting the item or picking it up both count, and you
do not need to keep it afterwards.

## Recipe unlocks

Every LDFL recipe also unlocks in the **recipe book** when you first hold its key ingredient: a
shield for the Bulwark Shield, a bow for the Bolt Driver and the Longshot Rifle, an emerald for the
Solace Staff, and so on. The full list is on [Items and recipes](items-and-recipes.md).
