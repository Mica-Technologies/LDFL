# Sounds and subtitles

Every LDFL ability has its own original, synthesized sound and its own subtitle, so with
**Options → Music & Sounds → Show Subtitles** on, a fight can be followed by ear alone. All of
them play in the **Players** sound category (the Mending Station's in **Blocks**), so their
volume follows those sliders.

| Sound id | Subtitle | Played by |
| --- | --- | --- |
| `ldfl:barrier_raise` | Barrier raised | Bulwark raising the barrier |
| `ldfl:barrier_hit` | Barrier absorbs a hit | The barrier blocking an attack |
| `ldfl:barrier_break` | Barrier shatters | The barrier breaking |
| `ldfl:rush` | Shoulder Rush | Bulwark's Shoulder Rush |
| `ldfl:shockwave` | Shockwave | Bulwark's Shockwave |
| `ldfl:tectonic_slam` | Tectonic Slam | Bulwark's ultimate |
| `ldfl:stone_skin` | Stone Skin | Monolith's Stone Skin |
| `ldfl:upheaval` | Upheaval | Monolith's Upheaval |
| `ldfl:bedrock_anchor` | Bedrock Anchor | Monolith's ultimate |
| `ldfl:bolt_fire` | Bolt fired | The Bolt Driver |
| `ldfl:sentry_deploy` | Sentry deployed | Forgewright's Deploy Sentry |
| `ldfl:sentry_fire` | Sentry fires | The sentry shooting |
| `ldfl:slag_surge` | Slag Surge | Forgewright's ultimate |
| `ldfl:longshot` | Longshot fired | The Longshot Rifle (louder and lower the more it was charged) |
| `ldfl:updraft` | Updraft | Kestrel's Updraft |
| `ldfl:marker_dart` | Marker Dart | Kestrel's Marker Dart |
| `ldfl:long_vigil` | Long Vigil | Kestrel's ultimate |
| `ldfl:flask_burst` | Flask bursts | Solace's Bloom Flask landing |
| `ldfl:tailwind` | Tailwind | Solace's Tailwind |
| `ldfl:sanctuary` | Sanctuary | Solace's ultimate |
| `ldfl:orb` | Resonant orb | The Tuning Rod |
| `ldfl:resonance` | Resonance | Chime's Resonance |
| `ldfl:ward_bell` | Ward Bell | Each ring of Chime's Ward Bell |
| `ldfl:crescendo` | Crescendo | Chime's ultimate |
| `ldfl:mending` | Mending Station heals | A Mending Station healing someone |
| `ldfl:ult_ready` | Ultimate ready | Your ultimate meter filling (heard only by you) |

A few actions use vanilla sounds instead: lowering the barrier, Plating, the wrench repairing a
sentry, throwing a Bloom Flask, and a Mending Station recharging.

Resource packs can replace any of these through `assets/ldfl/sounds.json`.
